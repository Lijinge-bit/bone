01修订说明与阶段决策

本稿依据《时序骨龄.docx》、用户上传的两份 CSV、Kaggle RSNA Bone Age 页面与 7 张实际影像抽查，以及本轮讨论更新。项目全称保留；当前首版名称为“单时相骨龄评估研究原型”。

本轮确认的阶段方向：先建立“单张影像＋性别 → 骨龄”的可验证闭环，再推进 ROI 检测、医院 DICOM 工作流与纵向联合预测。当前仅更新需求文档，不开发应用或训练模型。
修订点V0.2 决策原因
首版输入PNG 影像与性别为必需；实足年龄不是当前模型必需输入。现有表格只有影像 ID、骨龄标签与性别。
数据管理先建立样本清单；患者身份未知时保持未知。图片编号不能证明患者身份或多次随访关系。
ROI 与 DICOM保留为后续 P1；首版使用整图骨龄基线与原图阅览。当前缺少骨骼位置框；已抽查文件是 PNG。
解释与复核首版包含热力图、原图对照和人工复核意见。延续原文可解释性与辅助定位；临床签署另设准入条件。
联合预测时序、终身高、闭合时间窗与生长百分位列 P2。患者随访、身高和相应真实结局尚未提供。
验收分别记录数据准备、功能运行、模型指标和临床试用条件。页面可用、模型达标和临床有效是不同结论。
依据标记含义
原文要求Word 明确的研究目标及系统能力；不代表已实现。
检查证据CSV 全表统计、Kaggle 元数据和已实际查看的 7 张样例；不外推为全量图片结果。
阶段设计为形成首版闭环而新增或调整的需求，执行时以本稿范围为依据。
待确认标注标准、授权、患者关联、临床阈值等尚未确定的内容，不能视为已获批准。

原文提及的医院合作、伦理审批、500 例以上纵向数据、4090 工作站和学校 GPU 资源仍按计划／原文陈述记录；本次未核实其落实情况。V0.2 的阶段方向不等于所有临床和统计定义已确认。

02目标、指标与验收层次

数据可用

形成图片与标签对应清单、质量统计及可追溯的数据分区。

单次可评估

有效图片和性别可产生骨龄结果、关注区域热力图和复核记录。

效果可验证

在独立有标签数据上计算 MAE，并揭示不同性别与骨龄区间的误差。

产品长期目标仍为辅助医师分析当前骨龄、未来演进、成年终身高分布与闭合时间窗。首版仅验证单次研究能力，不将预测结果视为诊断或治疗建议。

指标原文目标阶段与判定
G-01 单次骨龄 MAE< 6 个月MVP 效果目标。单位、标签定义及评估协议确认后，在独立有标签测试集计算；未达标则标记“功能已运行、效果未达目标”。
G-02 成年终身高 RMSE< 4 cmP2；必须有可靠成年终身高结局，不作为首版验收项。
G-03 ROI mAP@0.5> 0.85，原文拟在 100 张标注图验证P1；先有骨骼框标注及独立测试图。首版整图骨龄模型不以此指标验收。
G-04 终身高预测区间希望控制在 ±4 cm 内P2 研究愿景；须同时定义覆盖水平、实测覆盖率及区间宽度，不能与 RMSE 混用。
G-05 未来骨龄曲线未来 2–4 年P2；预测时点与各跨度误差门槛待确认。
G-06 闭合时间窗给出估计时间范围P2；部位、闭合标签、删失处理和指标待确认。

单位约束：产品骨龄输出采用月，可补充“岁＋月”。CSV 原始数值保留；标签单位与标准须由数据说明核实后才能参与正式训练和效果验收。输出小数不代表标签具备相应精度。

03用户与使用场景

角色首版行为后续扩展
研究／数据人员整理已授权数据；核对图片与标签；查看质量、分区和评估结果。多中心数据治理与模型对比。
医师或获授权复核人员查看影像、预测及热力图，填写复核意见。按医院制度审核签署报告；支持纵向门诊工作流。
维护人员维护研究环境、可用模型及版本信息；访问数据遵循实际授权。账号角色、机构级权限与运维管理。
家长与体育选材人员当前无独立入口。原文关注对象／延伸场景，另行确认授权和产品范围。

首版场景

  1. 研究人员核对一批 PNG 与 CSV，处理缺图、重复和质量待复核项。
  2. 用户选择一张支持的 PNG，确认性别，检查原图与质量提示后发起骨龄评估。
  3. 用户查看预测骨龄和热力图，记录接受、存疑或需人工处理的意见。
  4. 评估人员在固定有标签测试集检查总体与分层误差，分析偏暗、低对比度和异常构图样本。

使用边界：公开研究样本在首版以“样本记录”管理；只有取得真实患者关联和临床授权后，才进入患者随访及正式报告流程。

04首版范围与后续规划

P0 表示当前 MVP 必需；P1 为单时相及临床流程增强；P2 为纵向联合预测。P1/P2 是保留的原项目目标，不因本轮分阶段交付而认定已完成或取消。

阶段范围进入条件
P0 · 单时相 MVPPNG 导入、性别确认、样本记录、质量提示、原图预览、骨龄预测、热力图、结果保存及人工复核意见；数据清单和独立评估报告。数据使用范围和标签定义核实；划分协议固定；模型、预处理和功能可复现。
P1 · 单时相增强骨骼 ROI 检测与标注、DICOM 去标识化和预处理、可验证的实足年龄输入增强、正式报告与医师签署、机构权限。具备相应标注、医院样本、元数据、流程和验证依据。不得用 PNG 支持情况代替 DICOM 验收。
P2 · 联合预测患者纵向档案、不规则时序、未来 2–4 年骨龄、终身高分布、闭合时间窗、历史贡献及标准生长曲线；图谱与文字解释。补齐患者和检查时间、身高与各任务真实结局；定义预测与解释评估口径。
另行评审家长端、体育选材端、PACS/HIS 接入、自动治疗建议。前三项需新增产品与授权范围；自动处方和治疗决策不属于现有辅助系统目标。
首版界面规则：主流程只显示可用的单次能力。后续模块可在规划说明中列出，功能入口隐藏或明确标记“后续阶段”；不使用固定成年身高、闭合日期或假曲线填充真实结果页。演示样例须持续标注“演示数据”。

05首版业务流程

01 选择样本导入 PNG 或从已登记样本选择，建立本次评估记录。
02 核对性别从表格读取并确认，或手动选择；记录来源。
03 检查质量识别解析失败、重复、构图及亮度等问题；必要时人工复核。
04 确认输入查看原图及处理预览，确认本轮可运行。
05 骨龄评估使用固定模型与预处理生成骨龄；失败显示原因。
06 查看解释叠加本轮热力图，与原图对照。
07 人工复核保留 AI 原值，独立记录意见与复核人。
08 保存结果保存输入指纹、模型版本、结果和复核历史。
情况处理
文件损坏／不支持编码或格式逐文件阻断并说明原因；保留同批成功项。
性别缺失或值非法等待确认，不能自动默认成某一性别；不要求补录不存在的实足年龄。
低对比度、过亮／过暗、背景大或目标不明确进入“待人工复核”；不凭单一亮度阈值直接删除。复核需记录可用、重选／调整或排除原因。
同一文件重复导入按内容指纹提示已存在，不静默覆盖。不同评估允许复用原文件并形成不同评估 ID。
推理失败或热力图失败分别显示状态；解释失败不展示旧图。保留有效骨龄输出，但本轮不能视为完整解释链路通过。
数据或模型更新后重算形成新结果版本并保留旧记录；不改写人工意见历史。

06页面与信息架构

页面P0 内容状态要求
P-01 样本工作台样本 ID、性别来源、图片质量、最近评估与复核状态；检索、新建和进入记录。空列表、加载、无权限、异常项。
P-02 导入与检查文件清单、CSV 对应状态、格式和尺寸、重复检查、质量待复核项。成功、失败、待核对；逐文件反馈。
P-03 阅片与评估PNG 原图、缩放平移、亮度／对比度、输入确认、预测骨龄与热力图。未运行、处理中、失败、解释失败、已完成。
P-04 结果与人工复核输入摘要、AI 骨龄、版本、热力图状态、人工意见与历史。未复核、已复核、存疑、需人工处理、历史版本。
P-05 数据与效果摘要固定数据分区、质量统计、总体和分层 MAE；可由离线报告承载，不强制首版管理后台。未评估、通过／未达目标、未知患者隔离状态。

PNG 的亮度／对比度仅改变显示；不宣称恢复 DICOM 原始窗宽窗位。除明确发起新的模型输入版本外，用户调节阅片显示不得悄然改变推理输入。

07详细功能需求

F-01 样本记录与未来患者档案

P0 记录；P2 随访

每次评估使用唯一记录 ID，保存样本 ID、文件指纹、性别及来源、质量状态、评估和复核历史。原始图片 ID 作为源数据标识，不自动充当患者 ID。

  • 实足年龄、患者 ID 和检查日期在首版可为空；不把导入日期当检查日期，不造出生日期。
  • 同一图片重复推理形成新评估，原图可复用；性别更正或输入变更保留旧值和影响范围。
  • P2 才按核实的患者关联与日期构建时间轴，支持缺失与不规则间隔。

验收要点：新记录不覆盖历史；来源不明的患者关系保持未知；样本模式不生成虚假的历年随访。

F-02 PNG 导入、匹配与质控

P0；DICOM 为 P1

支持本次样例验证过的 8 位灰度 PNG，并以内容解码而非仅扩展名判断文件。彩色、16 位或其他编码的支持须在验证后声明；未支持时给出原因。数据准备阶段支持批量清单核对，产品端至少支持单张导入。

  • 通过 CSV 的源图片 ID 与文件名主干精确关联；递归读取实际目录，记录真实路径，禁止按行号或目录顺序配对。
  • 区分缺图、多余图、重复 ID、重复内容和无法解析；同名但内容不同的文件标记冲突。
  • 性别统一映射；缺骨龄标签不影响推理，但不能进入监督训练和误差计算。
  • 保留原图；预处理产生可追溯衍生输入。质控流程详见第 11 节。
  • P1 扩展 DICOM 标签与烧录文字去标识化、DICOM → PNG、窗宽窗位及设备信息，并单独验证。

验收要点：匹配清单逐项有状态；支持的 PNG 可解码；未支持和损坏样本被明确阻断；待复核图片不自动当作通过。

F-03 影像浏览与骨骼 ROI

P0 浏览；P1 检测

原图可缩放、平移、调节显示亮度／对比度并重置；叠加热力图须与原图坐标一致，用户可对照关闭叠加。

  • 首版骨龄基线可使用整图或经验证的手部裁剪；手部裁剪不等于桡骨等多类别骨骼检测。
  • P1 按原文定位桡骨、尺骨、掌骨和指骨等 ROI；需新增类别、位置框标注与独立测试。
  • 自动骨骼框缺失时不生成假框；如后续支持手工修改，保留自动原始结果并生成新评估版本。

验收要点：显示调节不影响已保存推理值；图像变换可回溯；P1 的 ROI 另按 G-03 评估。

F-04 单时相骨龄评估

P0 核心

以有效影像和已确认性别为当前模型输入，输出骨龄（月）、任务状态、生成时间及版本。模型候选为原文的 ResNet-50 等预训练骨干，具体实现由后续技术方案决定。

  • 真实骨龄标签仅用于训练和离线评估，不作为预测时输入；文件名 ID 不作为发育特征。
  • 实足年龄在当前表格缺失，因此不作为首版必填项；没有实际年龄时不展示骨龄超前／落后判断或年龄差值。
  • 不从当前骨龄直接换算成年身高、剩余生长高度或闭合日期。
  • 异常数值、模型失败和不适用输入显示明确状态；不得通过静默裁剪数值掩盖模型问题。

验收要点：同一版本输入可复现到约定数值容差；不泄漏目标标签；MAE 按独立协议计算，G-01 通过与否如实记录。

F-05 纵向时序与未来骨龄

P2 保留

按原文处理同一患者历次检查、时间间隔与缺失模式，展示未来 2–4 年骨龄曲线。最低有效随访次数、预测步长及效果阈值需确认。

  • 仅使用预测起点之前可获信息；缺失不填成零；同日多张影像不自动当作多次随访。
  • 图表区分历史观测、当前评估和未来预测；保留数据截止日期及重算版本。

验收要点：具备真实患者序列和未来骨龄标签后，验证各跨度误差与不规则随访场景；首版不验收。

F-06 成年终身高与生长潜力

P2 保留

按原文展示成年终身高分布、中心统计量和预测区间；需要独立成年结局验证，父母身高、当前身高及治疗史是否必需由模型输入协议明确。

  • 区间显示覆盖水平；达到某身高的概率须定义为明确事件，例如 P(成年身高 ≥ 阈值)。
  • 剩余可增长身高仅在有效当前实测身高及成年预测可用时计算，并保留不确定性含义。
  • 同时检验 RMSE、区间覆盖与宽度；不强行缩窄至 ±4 cm。

验收要点：具备成年结局后验收 G-02/G-04；表格中的当前骨龄不能代替身高结局。

F-07 生长板闭合时间窗

P2 保留

明确目标骨骼、闭合定义及随访结局后，估计闭合时间范围。需考虑检查间隔造成的区间和删失；无验证能力时标记不可评估。

不将热力图或某次骨龄直接当作闭合结论，不生成自动用药或治疗时机建议。

验收要点：按独立闭合标签和冻结口径验证时间窗；本阶段不承诺精度或固定日期。

F-08 热力图、历史贡献与文字解释

P0 热力图；P2 历史与图谱解释

首版采用经验证的 Grad-CAM++ 或相应解释方法，展示当前骨龄输出对应的相对关注区域；可调透明度、开关和原图对照。

  • 解释绑定本轮图片、预处理与模型版本；映射回原图坐标并保留实际裁剪范围。
  • 热力图不是病变分割、骨骼检测真值、模型置信度或因果证据；不自动生成“生长板偏窄”等未经验证的文字。
  • 解释失败单独报错，不复用其他样本图；解释链路失败时本轮标记部分成功。
  • P2 按原文增加历史时点消融贡献、发育图谱叠加与有依据的自然语言提示；消融变化不默认是因果权重。

验收要点：坐标、颜色图例和版本一致；使用者能区分关注与诊断；当前流程具备成功热力图样本及失败路径验证。

F-09 生长曲线与百分位

P2 保留

按原文比较历次身高、骨龄与参考曲线。需补齐实足年龄、身高及日期，并明确参考标准及适用人群。

状态定义

  • 导入：待处理 → 解码／匹配 → 成功、待核对或失败；批量逐文件记录。
  • 质量：未检查 → 通过、待人工复核或拒绝；复核保留处理人、原因和时间。
  • 评估：待校验 → 待运行 → 运行中 → 成功、部分成功或失败；输入不满足条件时停留待补充状态。
  • 复核：未复核 → 已复核（接受／存疑／需人工处理），更正保留历史；不使用“已签署”冒充机构确认。

10模型基线与评估协议

10.1 首版基线

使用原文候选 ResNet-50 等预训练骨干建立整图／经验证手部裁剪的骨龄回归基线，融合性别。输入分辨率、灰度转通道方式和归一化依据骨干及实验确定并记录，当前不将某个实现细节写成已验证结论。Grad-CAM++ 等解释与最终选定模型配套验证。

协议项要求
输入／目标输入为影像与确认性别；目标为骨龄标签。ID、文件路径和真实骨龄不作为输入特征；实足年龄增强另立实验。
固定分区建议有标签数据按约 80%／10%／10% 划分训练／验证／留出测试，作为初始方案；比例、种子和清单在训练前固定，按分组情况允许调整。
分组优先同患者及重复／近重复组不可跨分区；患者标识不可得时，重复组隔离与性别／骨龄分层可作为研究基线，但必须注明“患者级隔离未验证”，不声称已完成患者独立验证。
无标签 200 张保留为预测集，不用于 MAE、调参、挑模型或重新划分有标签数据；输出预测不等于效果验收。
增强与统计先划分后增强；增强仅用于训练。需从数据估计的归一化等参数只使用训练分区；验证和测试不施加随机训练增强。
选择与测试使用验证集选模型和处理方案；锁定后在留出测试集报告最终结果。若因观察测试结果调整方案，需披露并重新建立独立检验。
指标MAE＝平均 |预测骨龄－参考骨龄|，以月报告；另给样本数、误差分布与有依据的不确定范围。
分层至少按性别、参考骨龄区间报告 MAE 和样本数；区间建议 0–<24、24–<72、72–<120、120–<168、≥168 月，冻结前可按样本分布调整；稀疏区间单列限制。
质量与捷径对暗图、低对比度、多余背景、文字／边框等分组分析；可用遮挡敏感性和人工热力图复核检查是否依赖非骨骼区域，不把热力图合理视为充分证明。
可复现保存数据与分区版本、随机种子、训练配置、权重标识、输入／预处理版本、运行条件及评估输出；每个排除样本有原因。

10.2 逐阶段研究路线

  • P0：完成可复现骨龄基线、总体／分层误差和热力图检查。未达 G-01 时记录失败并分析，不能为了达标丢弃难例。
  • P1：按独立标注比较整图与 ROI 方法（原文候选 YOLOv8／RT-DETR）；验证设备变化和实足年龄增强，明确每次新增输入的实际收益。
  • P2：按相同患者分区比较 LSTM／TCN，考虑不规则间隔和缺失、MMD 域自适应；终身高采用经验证的概率方法，分别检验精度和校准；闭合结局另定义删失和区间评估。

原文“首次引入”“显著优于”等描述须经文献和实验支撑，不作为当前已证实的产品结论。

主要风险与处置

  • 标签来源或单位不清：先核实再训练，保留原值和标准；不通过改标签或删难例追求达标。
  • 图片与患者关联未知：优先取得患者分组；研究基线披露限制，分组去重不能证明完全无患者泄漏。
  • 少样本和图像风格差异：分层报告，独立外部验证后才扩展适用范围；文字和边框可能造成捷径需检查。
  • 算力和预算：在实际硬件上测资源需求，选择适当输入与批量；原文 4090／V100／A100 资源未在当前环境确认。
  • 后续结局缺失：逐任务统计可用患者及标签，明确未完成能力，不由单次骨龄外推完整预测有效性。
