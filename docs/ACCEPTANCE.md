# 首版验收与边界

本项目实现 PRD V0.2 的单时相研究闭环，功能验收与模型目标分别记录。

## 已实现的能力

- 8 位灰度单帧 PNG 导入、文件类型／像素／大小限制、SHA-256 精确重复提示；重复导入打开原记录。
- 原图独立保存，PNG 阅览、缩放平移、亮度／对比度与重置；显示调节不改变模型输入。
- 性别确认、来源记录、乐观版本检查；无实足年龄时可评估，无虚构年龄或差值结论。
- 自动亮度等研究提示与人工质量审核；可接受／排除并记录原因。
- 真实 CPU 模型推理、异步任务状态、Grad-CAM 原图坐标映射、解释不可用时的部分成功状态。
- AI 原值与人工确认值／意见分离；更正输入后旧结果标为历史版本，旧记录保留。
- 样本搜索、状态筛选和分页；审计、固定分区、真实模型总体与分层误差展示。
- 200 张无标签图片预测脚本；没有计算不存在的真实测试误差。
- 打印友好的研究记录；没有冒充临床签署。

## 验证命令

```bash
python -m unittest discover -s tests -v
node --check app/static/app.js
# 服务启动、真实模型和样例准备后，运行真实浏览器闭环：
python scripts/check_browser.py
```

后端流程测试使用明确标注的测试替身检验状态持久化；真实模型测试另外检查实际权重、重复预测、热力图原图尺寸、损坏权重拒绝及升级前后的预测／空间关注分布。未准备真实模型和六张样例时，相关集成测试会明确跳过，不计为通过。0.2 版在 Python 3.14.8 / PyTorch 2.14.1 CPU 上 15 项通过、0 跳过，兼容检查另复测固定 1,260 张留出图片，详见 [升级记录](PYTHON314.md)。

浏览器验证脚本会在公开样例 1377 上留下标有“自动化功能验收”的质量与结果复核记录；这不代表临床医师审核。服务仅默认监听本机回环地址，当前是单用户研究环境。
