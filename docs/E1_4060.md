# 在 RTX 4060 上完成 PRD V0.4 的 E1 成对实验

本轮优先验证“让图像骨干适应骨龄任务是否优于继续只训练回归头”。云端没有 CUDA GPU；云端的末残差块 CPU 对照与本页的全骨干 CUDA 实验分别记录。CPU 结果不能当作 4060 的结果。

在包含 V0.3 权重和本轮新增脚本的 `bone-atlas` 目录操作。已有 CPU 环境可保留；GPU 使用独立解释器：

```powershell
py -3.14 -m venv .venv314-gpu
.\.venv314-gpu\Scripts\python.exe -m pip install -r requirements-gpu.lock
```

将同一 RSNA v2 原始 ZIP 放到 `data\rsna-bone-age-v2.zip`，并保留完整包附带的 `audit.json` 和 `manifest.jsonl`。原图不在完整包内；下载和固定缓存的详细要求见 [训练说明](TRAINING_V0.3.md)。

运行一组成对实验：

```powershell
.\.venv314-gpu\Scripts\python.exe scripts/run_e1.py --data .\data --output .\experiments
```

脚本先校验 V0.3 初始化权重 SHA、原图路径并执行真实 CUDA 前向／反向／AdamW 预检。预检失败会停止，不会转为 CPU。随后核验或创建 224 原图缓存，按顺序运行：

| 运行 | 配置 | 唯一实验差异 |
|---|---|---|
| frozen | `configs/train_e1_4060_frozen.json` | 60 轮上限内骨干始终冻结 |
| finetune | `configs/train_e1_4060_finetune.json` | 前 3 轮冻结，之后解冻全部骨干 |

两组从同一 V0.3 已训练完整权重起步，224 输入、物理 batch 8、AMP、BN 运行统计冻结、SmoothL1 β=0.5、相同学习率／余弦日程与早停、无图像增强。它们与启用增强的旧默认配置分开保存。比较只使用训练／验证数据；脚本不执行留出评估或模型注册。

每组实际按验证 MAE 选优／早停，最多 60 轮。结果保存在 `experiments\e1-时间-编号\`，其中 `suite.json` 记录所有运行目录和状态，各运行包含完整配置、初始化、环境、曲线、恢复文件和验证产物。

稳定性复核可在独立套件运行三个预设种子：

```powershell
.\.venv314-gpu\Scripts\python.exe scripts/run_e1.py --data .\data --output .\experiments --seeds 20261023 20261024 20261025
```

这是六个独立运行，不保证固定完成时长。先根据第一组实际吞吐、峰值显存和验证结果决定后续实验预算。比较方案时保留每次结果及均值／标准差；不能只报告最好的单次。

中断／失败后不要把更改 batch、分辨率或总轮数的配置塞进原恢复文件。保持原配置恢复：

```powershell
.\.venv314-gpu\Scripts\python.exe scripts/train.py --data .\data --resume .\experiments\你的套件\你的运行\checkpoints\latest.pt
```

需要降低 batch 时，新建配置和运行，例如物理 batch 4、梯度累积 2，并对两组保持同样调整。有效 batch 一致也不意味着浮点／BN 行为完全等价，应在报告保留实际设置。

按验证选择并锁定候选后，再进行明确标记的历史留出探索评估、CPU 预测／Grad-CAM 和注册／回滚检查，命令见 [训练说明](TRAINING_V0.3.md)。原有 MAE <6 月目标和新的独立最终数据要求保持；本页只提供可执行实验入口，不承诺效果分数。
