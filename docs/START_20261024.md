# 2026-10-24 完整研究项目包：开始使用

本包是可以单独安装的当前研究项目，不需要先安装V0.3或合并V0.4更新包。当前活动权重已内嵌，无需另跑权重下载或注册命令。应用版本仍为V0.3，最新可靠性报告为V0.4.1。

## Windows / PyCharm

1. 将 `BoneAtlas_Complete_20261024.zip` 解压到**新目录**，例如 `D:\BoneAtlas_20261024`，避免覆盖你现有项目和数据库。
2. 在PyCharm打开里面的 `bone-atlas` 文件夹。该目录应能看到 `app`、`scripts`、`requirements.lock` 和 `var`。
3. 在该目录的PowerShell终端依次执行：

```powershell
py -3.14 -m venv .venv314
.\.venv314\Scripts\python.exe -m pip install -r requirements.lock
.\.venv314\Scripts\python.exe scripts/check_runtime.py
.\.venv314\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

保持最后一个命令运行，在你电脑的浏览器打开 `http://127.0.0.1:8000`。创建虚拟环境成功时可能没有输出；第一条命令需要本机已有64位标准CPython 3.14。首次安装依赖需联网。PyCharm解释器选择本项目的 `.venv314\Scripts\python.exe`。

六张公开样例初始均为“待质检”，没有预填人工意见或预测；在界面确认性别和质量后再执行研究评估。质量提示仍需人工核对。

没有打包你的私有上传、现有业务数据库、虚拟环境、约10GB全量原图、训练缓存、优化器检查点或全部历史实验目录。源代码快照与研究运行包的范围不同；本包包含当前单次推理所需权重。

## 继续GPU训练需要另外准备

本包提供RTX 4060实验工具，但不包含完整训练原图。按照 [E1说明](E1_4060.md) 准备原图、固定缓存、独立GPU环境并完成实机预检。

E1冻结／解冻成对研究固定使用V0.3冻结ResNet初始化，不能用当前末块微调权重冒充。为避免在每个运行包重复放入另一份约96MB权重，本包没有携带该旧ResNet初始化；需要时从 [V0.3完整包](https://github.com/Lijinge-bit/bone/raw/refs/heads/main/downloads/BoneAtlas_MVP_0.3_Training.zip) 单独解压 `bone-atlas/var/models/resnet50-frozen-cpu-224.pt` 到本项目 `var/models/`，保留当前 `active.json`。该旧初始化SHA-256应为 `0a3eb7e2e11b427991d0d9e2ad2f219662a40c8d102147abb761fd788afbfd7b`。这一步只为后续E1研究，正常启动与当前模型预测不需要它。
