01

版本结论与本轮决策

本稿依据《时序骨龄.docx》、PRD V0.2／V0.3 与 2026-10-23 归档实验，更新事实、缺口和下一轮验收要求。项目全称保留为“时序骨龄与生长潜力联合预测系统”；当前产品仍是单时相骨龄研究工作台。

已确认的进展

真实 ResNet-50 冻结骨干＋性别回归头已训练并集成，CPU 推理／Grad-CAM、候选证据注册、回滚和浏览器闭环已有归档证据。

当前主要阻塞

MAE 尚未达到原目标；RTX 4060 全量微调没有实机结果；既有留出已被观察，患者级独立性和新的最终评估数据仍缺。

  1. 保留 MAE <6 月目标：不因已有改善而降低原门槛。
  2. 停止把增加弱模型轮数作为主线：优先验证预训练骨干的 GPU 微调，再逐项研究增强、损失、分辨率和裁剪。
  3. 继续复用已完成工具：不重复开发模型工厂、缓存、注册和工作台；补齐实机与效果证据。
  4. 研究包与效果验收分别判定：当前可交付研究包；完整 GPU 工程验收和正式效果验收均未完成。

文档版本为 V0.4，应用／完整项目包仍为 V0.3。本次交付为静态需求文档，不启动新训练，不改变活动模型或应用业务代码。V0.3 的“待开发／尚无新模型”描述保留为历史快照，由本稿更新当前事实。

2 · E2 增强以 E1 验证优者为参照，仅开启明确的轻度亮度／对比度增强。检查泛化与高估／低估段；验证无增强。旋转／平移须另立配置，确认腕部／指尖未被裁掉。P0；保留失败与无提升结果。
3 · E3 损失以当前验证优者为参照，分别比较 SmoothL1 β=0.1 与 L1，基准 β=0.5。β=0.5 / 0.1 在目标尺度对应 30 / 6 月转折，不代表能达到对应 MAE。P0 有条件；每次只改变损失方案，不同时改采样。
4 · E4 分辨率384 原图缓存对照 224；初始化、增强、损失与选择规则一致。先过显存预检；若 batch／累积改变，说明比较为方案整体变化；有效 batch 相同不保证 BN／数值完全等价。P1；资源不足则不执行，记录原因。
5 · E5 裁剪 / E6 采样手部裁剪与年龄采样分别实验；ROI 检测不混入本轮裁剪对照。裁剪需保留关键解剖并可逆映射；采样只改变训练分布，评估仍用原分布。不能按误差删难例。P1；由验证诊断决定是否开展，不据留出反复调参。

预先确定的选择规则

  1. 每次实验独立 run，保存配置、初始化 SHA、数据／缓存引用、环境、历史曲线、best／latest、状态、验证逐样本结果；不得覆盖活动模型。
  2. 每个运行按最低验证 MAE 选 checkpoint。记录无增强 train MAE、val MAE、各性别／年龄段 n、偏差、P90、有限性和超范围情况；分层可在最佳候选阶段完整计算，不把现有每轮总体日志描述成已有每轮分层能力。
  3. 先用一个固定种子成对筛查；对选出的方案及匹配参照用 20261023／20261024／20261025 三种子复核。方案按验证 MAE 均值排序，并报告每次值与标准差；方案内按最低验证 MAE 选部署候选。资源不足只完成单次时标“单次探索”，不能声称稳定性已确认。
  4. 下一轮研究晋级看验证集是否优于 12.7541 月及匹配参照，并同时披露尾部、分层与异常变化；不将最佳单次值包装成普遍收益。不预设未经验证的低龄／性别硬阈值。
  5. 锁定方案与权重后才执行显式评估；历史留出不用于实验排序。新的最终数据在方案冻结前保持不可见，评估后修改方案须新增研究轮次并披露暴露。
与现有默认配置的区别现有 GPU 模板启用 augmentation=true。本稿为分离“解冻”和“增强”因素，要求 E1 成对对照另存配置并关闭增强，E2 再单独开启。已保存运行及历史配置保持原样；新实验尚未执行。
