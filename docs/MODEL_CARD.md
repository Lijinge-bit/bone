## 历史 CPU 小模型说明

## 数据与划分

- 来源：[RSNA Bone Age / kmader](https://www.kaggle.com/datasets/kmader/rsna-bone-age)，版本 2。
- 标签表：12,611 条骨龄与性别；另有 200 条无骨龄标签记录。
- 已执行 12,811 张 PNG 与 CSV 的完整匹配、逐文件 ZIP CRC 验证、解码与原始像素重复检查。全部匹配成功，精确重复组为 0。
- 原始 CSV 与 ZIP 内 CSV 的 SHA-256 完全相同；全量数据不加入 Git。
- 按性别与骨龄区间分层，精确重复和相同 dHash 候选组保持同区：训练 10,091、验证 1,260、有标签留出测试 1,260。划分种子 `20261022`。
- dHash 仅对相同 256 位哈希候选分组，不是穷尽的近重复搜索。**数据无患者 ID 和检查日期，患者级隔离未验证。**
- 200 张无标签图片单独预测，不用于调参或计算 MAE。

## 实现选择

当前环境仅有 CPU（5 个可见核心），`torch.cuda.is_available()` 为 false。为先验证端到端流程，使用从头训练的轻量 CNN，而不是声称已完成预训练 ResNet-50：

- 输入：灰度 PNG 与性别；真实骨龄及图片 ID 不作为特征。
- 保持宽高比缩放，黑色填充至 96×96；灰度归一化为 [-1, 1]。
- 三层卷积（16/32/64 通道）、GroupNorm、SiLU，空间池化后与性别嵌入融合回归。
- 训练：20 轮、AdamW、训练集轻度亮度／对比度增强；无镜像或不受控解剖裁剪。
- 按验证集 MAE 选定第 20 轮，再运行有标签留出测试一次。
- 使用预测骨龄的 Grad-CAM 解释，映射回原图坐标；它不是 Grad-CAM++、病变分割、生长板检测或因果解释。
- 权重按 SHA-256 校验，加载使用 `torch.load(..., weights_only=True)`；校验失败停止预测。

PRD 保留了预训练骨干与 ROI 检测路线。当前小模型是可运行基线的资源折中，没有据此变更原文精度目标。

0.2 版升级推理运行环境至 Python 3.14 / PyTorch 2.14.1 CPU，原始训练环境仍为 PyTorch 2.7.1。没有重训或替换权重；固定 1,260 张留出图片重新执行兼容回归，MAE 仍为 19.2524 月。新旧样例预测与 Grad-CAM 的对比见 [Python 3.14 记录](PYTHON314.md)。

## 适用限制与下一步

1. 仅研究用途，未做医院试用、外部验证或中国儿童临床适用性验证。标签参考标准仍需核实。
2. Kaggle 许可字段为 `Other (specified in description)`；需核实原始数据条款，不能因可下载就推断允许所有商用或临床用途。
3. 图像文字、侧别标记、边框和额外手指可能产生捷径。当前热力图提供排查入口，没有证明已消除所有非解剖依赖。
4. 自动质控阈值是可追溯的研究提示，未经过临床标定；所有图片都要求人工核对，不能宣称具有可靠的自动质量判定能力。
5. 后续在验证集上比较较高分辨率、预训练 ResNet、手部裁剪和 ROI 方案。重复观察同一留出测试集进行改进时，应另建最终测试集或披露多次评估。
6. 时序、成年终身高和闭合时间窗仍需要真实患者随访与对应结局，当前模型不提供这些能力。
