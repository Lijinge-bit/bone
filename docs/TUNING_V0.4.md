# V0.4 首轮调校：让末端图像特征参与骨龄学习

本轮已完成真实训练、完整验证／探索留出评估、CPU 预测与 Grad-CAM、隔离浏览器闭环及新旧模型双向回滚。当前云端活动研究模型为 **`tail-adapt-seed20261023`**。应用版本仍为 V0.3；本页的 V0.4 指模型调校轮次。

验证 MAE **12.7541 → 12.1334 月**，下降 **4.87%**；同一历史固定留出 MAE **12.9245 → 12.4175 月**，下降 **3.92%**。**原 MAE <6 月目标仍未达到**。这是单种子、3 轮、CPU 末残差块微调，未执行 RTX 4060 全骨干 CUDA 训练，也没有新的独立最终／患者级验证。

## 本轮解决什么

原模型的整个 ImageNet 图像骨干保持冻结，只有性别嵌入和回归头接受骨龄监督。本轮研究“让末端图像块学习骨龄特征，是否优于继续只训练头部”。这是对关键限制的受控实验；结果支持进一步研究骨干微调，不能据此声称已经解决全部精度或低龄问题。

从同一个 V0.3 权重起步，两组固定 10,091 训练／1,260 验证的源 ID、224 输入、FP32、batch 16、种子 20261023、SmoothL1 β=0.5、学习率／余弦日程、无增强和冻结 BN 统计。第一轮两组均只训练头，第二／三轮仅候选组解冻 `features.layer4.2`。该末残差块与性别／回归头共同更新，更早的图像层保持冻结。

前段固定空间特征来自原始 224 输入，FP32 缓存用于减少重复 CPU 计算；没有从 96 缓存放大替代原图，没有缓存留出特征参与训练。八张验证原图上完整网络与缓存链路预测最大差为 **0 月**；完整 1,260 张验证的初始化 MAE 复现为 12.754104 月。

[预先锁定的实验协议](reports/tuning-v04-protocol.json)规定：按验证 MAE 选择，包含第 0 轮的未改动初始化；候选须比初始化及匹配冻结对照至少改善 0.05 月、且图像块确实发生更新，才能进入研究集成。最终选择在本轮新留出评估之前锁定。

**剩余缺点必须保留：**

- 0–<24 月只有 9 张留出，MAE **19.7976 → 19.9022 月，未改善**；该组偏差 +8.7400 月，不能称为低龄能力已解决。
- 24–<72 月仍有 +8.4767 月高估；72–<120 月仍有 +8.0145 月高估。总体 MAE 改善不等于各组偏差都改善。
- 当前最优 train / validation 为 **8.2195 / 12.1334 月**，差约 **3.9139 月**，大于原先约 2.3171 月，提示泛化仍是后续重点；不应仅增加轮数。

200 张无标签图已用新活动模型重算：**198 条有效、2 条 invalid_output**，异常源 ID 为 4389, 4539。相比 V0.3 的 199 有效／1 异常，异常数增加 1；没有骨龄真值，未计算 MAE，不能把总体有标签精度改善称为所有输入的有效率都提高。[无标签导出记录](reports/tuning-v04-unlabeled.json)

## 在你的电脑使用本轮更新

[下载 V0.4 调校更新包](https://github.com/Lijinge-bit/bone/raw/refs/heads/main/downloads/BoneAtlas_Model_Tuning_V0.4.zip)。它包含新权重、匹配的训练／评估／集成证据和新增训练工具，**需要 V0.3 完整项目**；未打包你的私有上传、数据库、旧权重、虚拟环境或原图缓存。

若本机仍为 V0.2，先将 [V0.3 完整包](https://github.com/Lijinge-bit/bone/raw/refs/heads/main/downloads/BoneAtlas_MVP_0.3_Training.zip) 解压到新目录。将更新包另解压到临时目录，再把其中 `bone-atlas` 文件夹**内部的文件和子目录**复制到 V0.3 项目的 `bone-atlas` 目录，合并同名目录。更新包没有 `var/`，解压不会切换活动模型或替换现有业务数据库。在项目目录确认候选并执行研究注册：

```powershell
.\.venv314\Scripts\python.exe scripts/register_model.py --candidate .\candidates\tail-adapt-seed20261023\export --evaluation .\candidates\tail-adapt-seed20261023\holdout-evaluation --integration .\candidates\tail-adapt-seed20261023\integration-check.json --storage .\var --research-only --operator Machenike --reason "V0.4 成对微调、评估与集成证据通过；研究用途，目标未达标"
.\.venv314\Scripts\python.exe scripts/check_runtime.py
```

解释器不存在时先按 V0.3 说明建立 CPU 环境并安装 `requirements.lock`。注册核对绑定的源码、权重和报告字节；缺项／不一致应按错误核查，不改校验值绕过。旧结果／复核保留；需要回滚时使用旧模型 ID `resnet50-frozen-cpu-224`。包内候选目录还提供与新模型绑定的 `unlabeled-predictions.csv` 和 sidecar，按需复制到 `var` 后可恢复界面中的 200 张预测导出；回滚后应使用对应模型版本的文件。
