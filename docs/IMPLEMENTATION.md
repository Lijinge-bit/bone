- 20 轮 CPU 训练，验证选择最佳轮次，留出测试报告见 `reports/model-evaluation.json`。
- 当前 15 项测试全部通过，包括真实模型重复预测、原图尺寸热力图、损坏权重拒绝及与旧环境的数值／空间关注分布回归；没有跳过真实模型检查。
